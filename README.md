# Cyber Security Governance Framework for an Australian Insurance Brokerage
A practical GRC portfolio project covering ISO 27001 alignment, cyber risk assessment, security policies, incident response, and third-party risk for an SME insurance brokerage.

## Project Overview

This project presents a practical cyber security governance framework for HarbourShield Insurance Brokers Pty Ltd, a fictional Australian small-to-medium insurance brokerage.

The project is designed to demonstrate real-world Governance, Risk, and Compliance skills for a cyber security, GRC, risk, compliance, or security analyst portfolio. It focuses on realistic business risks faced by an SME insurance brokerage rather than enterprise-only tooling or overly complex security frameworks.

The project includes governance documentation, asset management, cyber risk assessment, security policies, incident response planning, supplier security review, and an executive-level security summary.

## Business Scenario

HarbourShield Insurance Brokers Pty Ltd is a fictional Australian insurance brokerage with approximately 25 employees.

The business helps individuals and small businesses compare insurance products, submit applications, manage renewals, communicate with insurers, and support claims-related administration.

The organisation handles sensitive information, including:
- Customer personal information
- Insurance policy documents
- Claims information
- Financial records
- Business customer information
- Supplier and insurer communications
- Internal governance and operational documents

The company uses a realistic SME technology environment, including:
- Microsoft 365
- SharePoint and OneDrive
- Cloud-based insurance CRM
- Xero
- WordPress website
- Insurer portals
- Windows laptops
- Outsourced IT support
- SaaS and cloud service providers

## Project Objectives
The objectives of this project are to:
1. Design a practical cyber security governance framework for an Australian SME insurance brokerage.
2. Demonstrate ISO 27001-style thinking without claiming full certification.
3. Identify key information assets and assign business ownership.
4. Assess realistic cyber risks affecting the business.
5. Develop security policies suitable for a small-to-medium business.
6. Create an incident response plan and severity matrix.
7. Build a third-party supplier security review process.
8. Communicate cyber security risks and recommendations at an executive level.
9. Produce portfolio-quality documentation suitable for GitHub, Medium, and resume use.

## Key Focus Areas
This project focuses on the following cyber security and GRC areas:

| Area | Description |

| Governance | Security ownership, roles, responsibilities, decision-making, and reporting. |
| Risk Management | Cyber risk identification, scoring, treatment planning, and risk ownership. |
| Asset Management | Identification and classification of key information assets. |
| Access Control | User access, privileged access, MFA, account reviews, and joiner/mover/leaver process. |
| Data Protection | Data classification, handling, sharing, storage, and disposal. |

| Third-Party Risk | Supplier security review for outsourced IT, SaaS, CRM, hosting, and cloud providers. |
| Executive Reporting | Business-level summary of risks, maturity, recommendations, and roadmap. |

## Why This Project Matters

Many small and medium businesses handle sensitive information but do not have a dedicated cyber security team. Insurance brokerages are especially exposed because they handle customer information, policy records, financial details, insurer communications, claims documents, and third-party platforms.

This project shows how practical governance can improve security without overengineering the solution.

It demonstrates the ability to think like a cyber security analyst, GRC analyst, risk consultant, and business stakeholder at the same time.
